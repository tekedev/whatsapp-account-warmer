# WhatsApp Account Warmer — Activity Simulation Suite

> **Open Source Automation Showcase by Enes Teke (tekedev)**

---

## 🏛️ Executive Summary

**WhatsApp Account Warmer** is a browser automation tool that simulates natural messaging patterns and delays on WhatsApp Web.

---

## ⚡ Key Features

- **Playwright Automation:** Interfaces with WhatsApp Web interface seamlessly.
- **Randomized Delays:** Simulates realistic human typing speeds and pauses.

---

## 🛠️ Tech Stack

- **Core:** Python, Playwright, Asyncio
